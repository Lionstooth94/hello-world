# Support hello-world

This repository can support both free community usage and paid follow-on work.

## Paid options to offer

- priority support for teams using the material in production
- custom Stellar explainers for adjacent protocol topics
- implementation consulting for Stellar integrations
- sponsored improvements to documentation or tooling

## Sponsorship setup

- Keep the GitHub Sponsors entry aligned with the current repository owner or maintainer sponsor profile.
- Keep `.github/FUNDING.yml` current with real funding links.
- Add a personal site, booking link, or payment page before promotion.

## Publishing checklist

Current public contact paths are the GitHub profile and repository issues. Before broad outbound promotion for paid work, add:

- personal site or landing page
- business contact email
- booking or consultation link
- a consistent Gravatar that matches the GitHub profile

## Promotion checklist

- Share major updates on developer-focused social channels.
- Post concise explanations in communities where Stellar builders spend time.
- Link back to this repository from your GitHub profile and pinned projects.

## Signals to monitor

- which README sections get questions
- which issues turn into service requests
- whether users ask for related Stellar examples or tooling
- whether sponsor or contact links generate follow-up conversations
